# git-practice

A practice repository for learning core Git and GitHub workflows.

## Useful Git Notes

- `git clone <url>`: Download a remote repository to your local machine.
- `git checkout -b <branch>`: Create and switch to a new branch.
- `git status`: Check modified, staged, and untracked files in the working directory.
- `git add <file>` & `git commit -m "<message>"`: Stage and record changes in Git history.
- `git push -u origin <branch>`: Upload local commits to GitHub and set upstream tracking.
- `git stash` / `git stash pop`: Temporarily save uncommitted changes and reapply them later.
- `git diff`: Inspect line-by-line changes between commits or branches.
